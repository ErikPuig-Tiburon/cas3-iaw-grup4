## Objectiu

Construir una interfície clara per professorat i alumnat, visualment atractiva i prou ordenada per sumar punts a la rubrica.

## Disseny aplicat

El projecte utilitza un estil visual propi:

- fons orbital
- HUD superior de sessio
- sidebar de navegacio
- targetes i taules amb separacio visual
- tipografies combinades per donar identitat

## Vistes de professorat

Les pantalles principals del professorat son:

- dashboard amb resum
- alumnes
- material
- incidencies
- assignacions
- usuaris
- detall d'alumne

## Vistes d'alumnat

L'alumnat veu:

- dispositius assignats
- estat de les incidencies vinculades

## Responsivitat

El CSS adapta:

- layout general
- header de sessio
- sidebar
- taules amb scroll
- botons i formularis

S'usen `CSS Grid`, `Flexbox`, media queries i components reutilitzables.

## Relacio amb la rubrica

Aquest document ajuda a defensar:

- codi ben estructurat
- treball ben estructurat
- visualment atractiu
- funcionalitats extres

## Funcionalitats extres visibles

- dashboard de professorat
- sidebar de navegacio
- panell separat per alumnat
- tema visual propi
- documentacio publicada a `/phpdoc/`

## Conclusio

La capa visual no es un afegit superficial: ajuda a ordenar el projecte, facilita la navegacio i suma valor en l'apartat de treball estructurat i visualment atractiu.
